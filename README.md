# Welcome, Tamriel Adventurer!

This repository is home to my collection of add-ons for [The Elder Scrolls Online](https://www.elderscrollsonline.com). From map and minimap enhancements to crafting helpers, housing tools, inventory filters and quality-of-life improvements, these add-ons are built to make your time in Tamriel a little smoother.

## Where to Get the Add-ons

The easiest way to install and keep them up to date is through [ESOUI](https://www.esoui.com/), the home of officially released ESO add-ons from many different authors, including me. Releases are published there.

This repository contains the source code. If you want to follow development, report a bug or suggest a feature, you are in the right place.

## Repository Layout

- **`Addons/`** – the add-ons and the libraries they depend on (e.g. `LibAsync`, `LibGPS`, `LibCustomMenu`).
- **`Tools/`** – helper scripts and utilities used to package and maintain the add-ons.

## Manual Installation

1. Copy the add-on folder(s) you want from `Addons/` into your ESO add-ons directory:
   - Windows: `Documents\Elder Scrolls Online\live\AddOns`
   - macOS: `~/Documents/Elder Scrolls Online/live/AddOns`
2. Install any required libraries the same way.
3. Enable the add-ons in the in-game add-on menu.
